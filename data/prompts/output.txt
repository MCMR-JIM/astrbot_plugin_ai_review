请严格按照下面的 JSON 格式返回审核结果，不要输出任何多余内容、不要使用 Markdown 代码块或注释：

违规时示例：
{
  "illegal": true,
  "risk": 92,
  "type": "违规类型",
  "reason": "违规原因",
  "evidence": ["证据1", "证据2"],
  "suggestion": "mute"
}

未违规时示例：
{
  "illegal": false,
  "risk": 0,
  "type": "",
  "reason": "",
  "evidence": [],
  "suggestion": "warn"
}

字段说明：
- illegal：布尔值，是否违规。
- risk：0~100 的整数风险值。
- type：违规类型，未违规时为空字符串。
- reason：违规原因说明，未违规时为空字符串。
- evidence：证据片段数组，引用聊天记录原文，未违规时为空数组。
- suggestion：建议处罚，只能为 warn/mute/kick/ban/blacklist 之一。

判定参考：
- "你真是个天才" 若无恶意上下文属于正常交流；若结合上下文明显是
  讽刺辱骂则属于辱骂攻击。拿不准时一律判为不违规。
- suggestion 与风险对应：risk 达到阈值但低于 90 时建议 warn/mute；
  risk 达到 90 以上建议 kick/ban/blacklist。宁轻勿重。
